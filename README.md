# StudentManagementAPI

A simple RESTful API built with **Java** and **Spring Boot** to create, retrieve, update and delete student records. Developed as Task 2 of the NexLevr Java Development internship.

**Author:** Monika S. · B.Tech. Information Technology, II Year (IT-B)

## Features

- CRUD endpoints for students (`/api/students`)
- Correct HTTP status codes: 201, 200, 204, 400, 404
- Input validation (blank fields, email format, year 1–4) with clear JSON errors
- Global exception handling (no stack traces exposed)
- Interactive Swagger UI / OpenAPI documentation
- Automated tests with Spring Boot Test and MockMvc

## Technologies

Java 21 · Spring Boot 3.5.0 · Spring Web · Bean Validation · springdoc-openapi 2.8.9 · JUnit 5 / MockMvc · Maven (wrapper included)

## Architecture

Client / Swagger UI → `StudentController` → `StudentService` → in-memory `ConcurrentHashMap`. Errors go through `GlobalExceptionHandler`. See [docs/architecture.md](docs/architecture.md) and [docs/architecture.svg](docs/architecture.svg).

## Endpoints

| Method | Endpoint | Purpose | Success | Errors |
|---|---|---|---|---|
| POST | `/api/students` | Create a student | 201 | 400 |
| GET | `/api/students` | Get all students | 200 | – |
| GET | `/api/students/{id}` | Get one student | 200 | 400, 404 |
| PUT | `/api/students/{id}` | Update a student | 200 | 400, 404 |
| DELETE | `/api/students/{id}` | Delete a student | 204 | 400, 404 |

### Validation rules

| Field | Rule |
|---|---|
| `id` | Generated by the server (unique, never reused). Any id in the request body is ignored. |
| `name` | Required, not blank, max 100 characters |
| `email` | Required, not blank, valid email format |
| `department` | Required, not blank, max 100 characters |
| `year` | Required, between 1 and 4 |

### Sample request (sample data)

```http
POST /api/students
Content-Type: application/json

{"name":"Monika S.","email":"monika@example.com","department":"Information Technology","year":2}
```

Response `201 Created`:

```json
{"id":1,"name":"Monika S.","email":"monika@example.com","department":"Information Technology","year":2}
```

Error response `400 Bad Request` (example):

```json
{
  "timestamp": "2026-10-11T10:15:30Z",
  "status": 400,
  "error": "Bad Request",
  "message": "Validation failed",
  "details": ["name: name must not be blank"]
}
```

More examples: [docs/api-testing.md](docs/api-testing.md).

## Testing

```powershell
.\mvnw.cmd test
```

`StudentControllerTest` covers create, get all, get by id, update, delete, validation errors, 404s and invalid ids. Tests create their own data, so they do not depend on each other or on run order.

## Current limitations

- Storage is **in memory**: all students are lost when the application stops or restarts.
- No authentication, no pagination, no duplicate-email check.
- Not deployed; Swagger is available on localhost only.

## Future improvements
